🚀 Missão Espacial

Sobre o jogo

Missão Espacial é um jogo de aventura em que o jogador controla um astronauta e explora planetas para encontrar recursos e ajudar a salvar a Terra.

Funcionalidades

- Escolha de planetas.
- Exploração espacial.
- Coleta de recursos.
- Sistema de pontuação.
- Sistema de vidas.
- Três fases de aventura.

Regras

- O jogador começa com 3 vidas.
- Cada recurso vale 10 pontos.
- Estrelas de energia valem 5 pontos.
- Asteroides fazem perder uma vida.
- É necessário coletar pelo menos 2 recursos para vencer.

Linguagens utilizadas

- Python
- C
- Java

Objetivo

Desenvolver um jogo educativo para praticar programação, lógica e criatividade.
